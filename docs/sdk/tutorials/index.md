# SDK Tutorials

Tutorials are happy-path walkthroughs for building with Space.

- [Your First Space App](/sdk/tutorials/your-first-space-app) — run the Snake example and inspect the app, hostable module, and app-owned logic.
- [Add a Command](/sdk/tutorials/add-a-command) — expose a host-invocable command from a hostable app.
- [Publish an App](/sdk/tutorials/publish-an-app) — package an independent app with Space's reusable bundle workflow.
