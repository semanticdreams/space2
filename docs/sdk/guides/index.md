# SDK Guides

Guides solve focused SDK authoring tasks for builders who already know the core app, host, capability, runtime facet, extension, command, and package concepts.

- [App Layout](/sdk/guides/app-layout) — organize a Space app repository around assets, modules, tests, and release automation.
- [Hostable Runtime Apps](/sdk/guides/hostable-runtime-apps) — write apps that can run inside different hosts by requesting capabilities.
- [Embedded Workspace Hosting](/sdk/guides/embedded-workspace-hosting) — mount an app inside a Space workspace and clean it up safely.
- [Graph Extension Units](/sdk/guides/graph-extension-units) — register graph-exposed node types through extension descriptors.
- [UI Surfaces](/sdk/guides/ui-surfaces) — target host-provided HUD, canvas, and scene presentation surfaces.
