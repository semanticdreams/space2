# SDK Docs

SDK docs are for people building apps, extensions, widgets, worlds, workflows, and independent applications with Space.

## Who This Is For

Use these docs when you want to build on Space rather than only run the built-in experience. The SDK pages focus on builder-facing contracts for apps, hosts, capabilities, runtime facets, extensions, commands, packages, widgets, worlds, workflows, and standalone applications that run with Space.

When an SDK topic depends on project internals, this section links deeper to Developer Docs instead of duplicating maintainer workflows here.

## Start Here

- [Getting Started](/sdk/getting-started) — choose an entry point and run an existing Space app example.
- [SDK Concepts](/sdk/concepts) — learn the builder-facing vocabulary used throughout these docs.
- [Tutorials](/sdk/tutorials/) — follow learning paths for building with Space.
- [Guides](/sdk/guides/) — solve specific builder tasks.
- [Reference](/sdk/reference/) — look up current contracts, required inputs, and expected failures.
- [Examples](/sdk/examples/) — find copyable starting points from existing examples.
- [Developer Docs](/dev/) — inspect internals, rationale, and maintenance workflows when SDK docs link deeper.

## Stability Note

Space's formal SDK stability and versioning policy has not been defined yet. These pages describe current builder-facing contracts without promising long-term public API stability.
