# SDK Docs

SDK docs are primarily module references for people building apps, extensions, widgets, worlds, workflows, and independent applications with Space.

## Who This Is For

Use these docs when you want to build on Space rather than only run the built-in experience. Start with the module reference when you need to know which reusable ecosystem modules exist, how to import them, what APIs they expose, and which errors or platform constraints to expect.

The SDK also keeps builder-facing contracts for apps, hosts, capabilities, runtime facets, extensions, commands, packages, widgets, worlds, workflows, and standalone applications that run with Space.

When an SDK topic depends on project internals, this section links deeper to Developer Docs instead of duplicating maintainer workflows here.

## Stability Note

Space's formal SDK stability and versioning policy has not been defined yet. These pages describe current builder-facing contracts without promising long-term public API stability.
