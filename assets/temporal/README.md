# Temporal Runtime Data

This directory contains deterministic runtime data roots for the complete temporal library. Current packaged seeds include the selected CLDR corpus under `icu/cldr-seed/`, the `US-FED` 2026-2027 holiday corpus under `holidays/us-federal-seed/`, and the offline natural-language phrase seed under `natural/seed/`. Other roots remain reserved until manifest provenance is recorded and validation is expanded.
